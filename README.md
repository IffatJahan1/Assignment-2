# 🎬 Movie Explorer

A responsive React application to browse, search, and view details of movies and TV shows.

## ✨ Features
- Browse popular TV shows and movies
- Search movies by title
- Detailed modal view (rating, genres, summary, network)
- Fully responsive design (mobile, tablet, desktop)
- Pagination for browsing

## 🛠️ Tech Stack
- React (Vite)
- React Router DOM
- Tailwind CSS
- TVMaze API

## 🚀 Setup

```bash
npm install
npm run dev
Then open http://localhost:5173/
